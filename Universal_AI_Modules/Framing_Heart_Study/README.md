# 🫀 Heart Disease Risk Prediction (Logistic Regression, Python, Scikit-learn)

An end-to-end machine learning project to **predict the 10-year risk of coronary heart**
**disease (CHD)** using patient demographic, behavioral, and medical data from the Framingham
Heart Study.
The project covers the full ML pipeline: data exploration → preprocessing → model training → evaluation → visualization.

## 📌 Task Description

The **World Health Organization (WHO)** estimates that 12 million people die annually due to heart disease, with cardiovascular diseases accounting for **50% of all deaths** in developed nations.
Early risk prediction can help high-risk individuals make lifestyle adjustments, potentially reducing medical complications.
This project aims to identify significant heart disease risk factors and forecast overall risk using **logistic regression**.

## 🛠 Pipeline

1. Exploration of the Dataset – Load .csv file and inspect data structure.

2. Baseline Classifier – Implement a simple logistic regression model to establish a performance benchmark.

3. Data Preprocessing – Handle missing values, encode categorical variables, and scale numerical features.

4. Model Training – Train logistic regression on the processed dataset.

5. Evaluation – Assess model using accuracy, precision, recall, and confusion matrix.
